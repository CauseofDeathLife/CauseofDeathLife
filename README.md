## 🎙️ Asirea — AI voice agent that operates software for the user

Built for older adults and people with little digital experience: the user speaks, and Asirea operates the software for them through browser automation, in Spanish or English. Runs 100% locally, with no cloud APIs. One generic core with interchangeable domain modules, shown on two different kinds of software.
